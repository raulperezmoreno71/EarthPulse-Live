# Activación de dbv-specs-ops

Este proyecto sigue la metodología **Spec-Driven Development (SDD)**.

Antes de proponer código o un plan, lee `dbv-specs-ops/docs/MASTER_PROMPT.md` y sigue su flujo. Carga también `dbv-specs-ops/project.config.md`, `dbv-specs-ops/docs/SPECIFICATIONS.md`, `dbv-specs-ops/docs/ARCHITECTURE.md`, `dbv-specs-ops/memory.md` y `dbv-specs-ops/task.md`.

Los archivos de control y persistencia del framework se mantienen dentro de `dbv-specs-ops/`; el código de la aplicación vive en la raíz del proyecto.
