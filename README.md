# EarthPulse Live

> Panel geoespacial de eventos naturales reales y cercanos al tiempo real.

EarthPulse Live reunirá datos públicos de USGS y NASA EONET en una experiencia visual diseñada para explorar terremotos, incendios, tormentas, volcanes y otros fenómenos naturales. Cada evento conservará su procedencia y fecha de sincronización para que la demostración sea verificable.

## Estado

El proyecto se encuentra en fase de especificación y planificación. La implementación comenzará tras aprobar el plan técnico incluido en `dbv-specs-ops/implementation_plan.md`.

## Stack previsto

- React 19, TypeScript y Vite.
- Java 21 y Spring Boot 4.1.
- PostgreSQL y Flyway.
- Leaflet y Recharts.
- Docker Compose para desarrollo local.

## Fuentes de datos

- USGS Earthquake GeoJSON Feed.
- NASA Earth Observatory Natural Event Tracker (EONET) v3.
