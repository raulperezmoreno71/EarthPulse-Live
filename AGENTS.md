# Codex project activation

This project uses the **dbv-specs-ops** Spec-Driven Development workflow.

Before proposing code or a technical plan, read and follow:

1. `dbv-specs-ops/docs/MASTER_PROMPT.md`
2. `dbv-specs-ops/project.config.md`
3. `dbv-specs-ops/docs/SPECIFICATIONS.md`
4. `dbv-specs-ops/docs/ARCHITECTURE.md`
5. `dbv-specs-ops/docs/DESIGN.md` when the project has a user interface
6. `dbv-specs-ops/memory.md`
7. `dbv-specs-ops/task.md`

Treat the files under `dbv-specs-ops/` as the framework control plane. Keep application source code and product documentation in the project root unless the master prompt says otherwise.
